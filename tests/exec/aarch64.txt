# tests/exec/aarch64.txt - the execution tests on aarch64
# (tools/exectest_a64.py; docs/aarch64.md, "Tests").
#
#   NAME skip REASON     the test does not apply on aarch64
#   NAME xfail REASON    a known failure on aarch64 (must fail)
#   NAME expect REASON   the aarch64 output differs by design; it is
#                        tests/exec/aarch64/NAME.expect
#
# `expect' files whose only change is the order of bytes in `exec_$log_mem'
# dumps of words, longwords and register-sized sets (little-endian; owner
# 2026-11-12) were checked to hold the same bytes as the m68k expectation
# on each line, every other line unchanged.
