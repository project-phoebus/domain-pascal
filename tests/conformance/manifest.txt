# Image-conformance manifest, run by `make conform' (tools/conform.py manifest).
#
# One unit per line:  FILE SPEC... [--section-addr SEC=0xADDR]... [ALIGN] [A5]...
#   FILE  path from the repository root; a .pas file is compiled with
#         target/debug/dpc into tmp/conform/FILE/ first (with
#         --fragment-origin unless the unit is a whole map module), a .s
#         file is used as is.
#   SPEC  NAME | NAME:LEN | 0xADDR | 0xADDR:LEN   (LEN hex).  NAME is a map
#         name; 0xADDR is a module-local routine the map does not name.
#         The routines of a unit must be contiguous in the image.
#   ALIGN loop-align=on | loop-align=off | loop-align-off-from=ROUTINE,
#         forwarded to dpc (.pas units only; README.md, "Loop alignment
#         on and off"; tools/loopalign.py switch SEG).
#   A5    a5-always-from=ROUTINE, a5-always=ROUTINE,..., a5-absolute=
#         ROUTINE,..., each at most once, forwarded to dpc as --a5-...
#         (.pas units only; README.md, "Module data"; tools/a5survey.py
#         switch SEG).
#
# handasm/ entries are harness fixtures transcribed by hand from the image,
# not compiler output.
