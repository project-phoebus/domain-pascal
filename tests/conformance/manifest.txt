# Image-conformance manifest, run by `make conform' (tools/conform.py manifest).
#
# One unit per line:  FILE SPEC... [--section-addr SEC=0xADDR]... [ALIGN] [A5]...
#   FILE  path from the repository root; a .pas file is compiled with
#         target/debug/dpc into tmp/conform/FILE/ first (with
#         --fragment-origin unless the unit is a whole map module), a .s
#         file is used as is, a .o file (a prebuilt object: dpc's
#         runtime) is not even assembled.
#   SPEC  NAME | NAME:LEN | 0xADDR | 0xADDR:LEN   (LEN hex).  NAME is a map
#         name; 0xADDR is a module-local routine the map does not name.
#         The routines of a unit must be contiguous in the image.
#   SEC   a data section, or a code section of the unit other than its
#         routines' (named sections, README.md), placed at 0xADDR.
#   ALIGN loop-align=on | loop-align=off | loop-align-off-from=ROUTINE,...
#         (one ROUTINE per code section),
#         forwarded to dpc (.pas units only; README.md, "Loop alignment
#         on and off"; tools/loopalign.py switch SEG).
#   A5    a5-always-from=ROUTINE,..., a5-always=ROUTINE,..., a5-absolute=
#         ROUTINE,..., each at most once, forwarded to dpc as --a5-...
#         (.pas units only; README.md, "Module data"; tools/a5survey.py
#         switch SEG).
#   MODS  module-routines=ITEM,... (.pas fragments only): routines of
#         the unit's map module outside the unit, declared `extern' in it
#         and called with `bsr' as the original did; forwarded to dpc as
#         --module-routine=ROUTINE=0xADDR with the map address.  An ITEM
#         NAME=0xADDR is a module-local routine the map does not name,
#         declared `internal; extern' as NAME in the unit (test-only;
#         README.md, "Routines outside the unit").
#   ENCL  enclosing=NAME (.pas fragments only): the unit's routines are
#         nested in routine NAME (dpc's symbol), whose code follows them
#         at the unit's end; it is compiled with them and not compared
#         (README.md, "Nested routines").
#   GLOB  global=NAME,...: map names the unit must also define as global
#         code symbols (at their map addresses) that are no routine of
#         their own, e.g. a routine's second name (M$OIU$LLL).
#
# handasm/ entries are harness fixtures transcribed by hand from the image,
# not compiler output.
